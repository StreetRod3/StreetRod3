# 1956 Corvette

The game's model is `assets/cars/sr1-c56.glb`, converted from Street Rod 1's Corvette. It came out about a third too big; `tools/rescale_car_glb.py` scaled it to the real car (width ×0.801, height ×0.870, length ×0.755, the length set by the wheelbase so the arches stay over the wheels).

## Dimensions
